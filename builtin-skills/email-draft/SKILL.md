# Email draft

Use this skill when the user asks to write, rewrite, or answer an email.

## Procedure

1. Identify recipient, goal, tone, and required facts.
2. If critical facts are missing, use neutral placeholders rather than inventing.
3. Keep the email concise and easy to scan.
4. Include a subject line when useful.
5. Avoid over-apologizing unless the user explicitly wants that tone.
