⚠️ Why Web Speech API isn't used:

✅ How Horizon v5 works:
1. Hit 🌅 Wake → Horizon starts listening (every 2 s)
2. Say "Horizon" (or "Горизонт" / "Хорайзон" if you prefer Russian)
3. Horizon transcribes via Groq Whisper (free!)
4. Recognises the wake word → answers → types your next utterance live
5. Speak the command → it sends automatically

Needs a Groq key for wake word + voice. Free at console.groq.com
